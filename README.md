# Portfolio

Personal portfolio site built with React, TypeScript, Vite, and Three.js.

## Tech Stack

- React 19 + TypeScript
- Vite
- Three.js (`@react-three/fiber`)
- GSAP + Lenis
- Tailwind CSS

## Getting Started

```bash
cd app
npm install
npm run dev
```

## Build

```bash
npm run build
```

Hasil build tersimpan di `app/dist`.
